# CivicFix AI Scripts

This folder contains helper scripts for running the project locally without Docker.

## Scripts

### check-tools.bat

Checks whether Node.js, npm, PHP, Composer, Python, pip, and MySQL command line are installed.

### setup-frontend.bat

Installs frontend npm dependencies.

### run-frontend.bat

Runs the Next.js frontend on:

http://localhost:3000
